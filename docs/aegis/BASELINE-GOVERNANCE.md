# Baseline governance

- Product and security contracts are authoritative; baseline records summarize rather
  than replace them.
- Update a baseline when an accepted contract, architecture owner, upstream pin, or
  verification command changes.
- Keep facts, assumptions, and unknowns distinct.
- A baseline change must cite the source and travel with the plan or implementation that
  required it.
- Historical records remain in Git; do not silently rewrite evidence to make a plan look
  current.
