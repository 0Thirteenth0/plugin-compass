# Security Policy

Plugin Compass is a local, read-only metadata analysis tool. Report suspected command execution, credential access, path traversal, unsafe declaration handling, or recommendation-gate bypasses through the repository's private security-reporting channel. Do not include real credentials, customer data, or private plugin contents in a report.

The maintained `0.1.x` line receives security fixes. A scanner finding is evidence to investigate and is not, by itself, a guarantee of safety or exploitability.
