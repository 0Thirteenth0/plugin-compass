# Security policy

Compass Builder `0.1.x` receives security fixes. Report suspected worker-clone escape,
write-scope bypass, unsafe Git mutation, approval or sandbox bypass, credential access,
receipt forgery, stale-head acceptance, or verification bypass through the repository's
private security-reporting channel.

Do not include credentials, private keys, customer data, or unrelated plugin contents in
a report. A scanner finding is investigation evidence and is not by itself proof of
exploitability or safety.
